# from_antigravity_模块筛选回执

> 本回执针对用户反馈「点模块行应当只看该模块的用例」进行修复与 CDP 真实实测验收。

---

## 一、问题根因与修改方案

### 1. 根因
此前版本将模块筛选事件仅绑定在分类名称文本节点（`.cat-name`）上，而整行（`.nav-cat-header`）的点击事件绑定的是折叠/展开逻辑。用户点击整行空白处或药丸时，触发的是折叠而非筛选，导致右侧列表未发生过滤。

### 2. 行为解耦规范
依据派单要求，将点击区域事件严格分流：

| 点击位置 | 行为实现 | 代码逻辑 |
|---|---|---|
| **模块行**（名称、数量药丸、整行空白处） | **只看该模块全部用例**；再次点击同一模块行 → 回到全部 | 挂载在 `header.onclick` 上，更新 `gState.moduleFilter` 并高亮该行 |
| **`▾` 箭头** | **仅折叠 / 展开分类树**，右侧列表严格不变 | `arrow.onclick` 触发 `e.stopPropagation()`，仅切换 `.collapsed` |
| **复选框 `☑`** | **仅改变该模块用例勾选**，右侧列表严格不变 | `chk.onclick` 触发 `e.stopPropagation()`，仅同步 `gState.selectedCases` |

### 3. 一致性与互斥逻辑
- **模块筛选与搜索框互斥**：点击模块行时自动清空搜索框与 `gState.searchKeyword`；搜索框输入关键字时自动重置 `gState.moduleFilter = 'ALL'`。
- **「全部」按钮一键复位**：点击顶部「全部」按钮一键清空模块筛选高亮、清除关键字并完全恢复全量 66 条用例。
- **明显高亮样式**：选中模块行应用 `.nav-cat-header.active`（浅蓝底色 + 粗体蓝字），数量药丸（`.nav-pill`）呈现高亮蓝色，视觉识别度清晰。
