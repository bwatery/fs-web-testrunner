## 四、涉及代码文件与改动说明

1. `fs_runner/browser/runner.py`:
   - 提取并暴露 `UI_SUPPORTED_CASES` 与 `run_case_ui(session, case_id, ...)`。
   - 修复 `_run_l4_048` 单独执行时缺少患者节点点击的问题。
2. `fs_runner/cases/closed_loop/closed_loop.py`:
   - 声明 `UI_SUPPORTED_CASES`，统一为 66 条 Flow 挂载 `flow.ui_verify`（支持的为函数包装器，其余为 `None`）。
   - 改造 `run(...)` 循环：支持 `enable_ui` / `browser_session`，双腿联合执行，拼接证据与备注，严格执行界面腿失败熔断。
3. `fs_runner/cases/closed_loop/__init__.py`:
   - 导出 `UI_SUPPORTED_CASES`。
4. `fs_runner/cli.py`:
   - 修复老式直接传参拦截漏洞：增加标准子命令保护，避免 `--ui` 拦截 `run` 命令。
   - `p_run` 增加 `--ui`、`--windowed`、`--standalone`、`--slowmo`、`--screenshot`、`--mutation` 参数。
   - `run_closed_loop` 增加浏览器生命周期管控：开跑前判别是否有界面腿用例，无则输出提示不开浏览器，有则拉起 Chrome + 登录 + 跑完在 `finally` 安全回收。
5. `fs_runner/ui/runner_bridge.py`:
   - 修复 `start_run` 中的命令构建：闭环运行模式下勾选「窗口模式」时，透传 `--windowed` 与 `--slowmo`。
