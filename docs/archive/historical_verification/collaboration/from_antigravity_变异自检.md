## 一、自检机制与实现

1. **变异切入点**：通过动态包装 `oracledb.connect`，拦截游标 `cursor` 的 `fetchone` / `fetchall` / `fetchmany` / `__iter__`。
2. **防假崩过滤**：根据 `cursor.description` 提取列名，**严格跳过列名中包含 `ID` 的主外键/字典代码列**，防止因外键找不到而发生底层崩溃；
3. **数值扰动**：对其余所有数值列（兼顾 `int` 和 `float`），统一注入 **`+1` 变异扰动**。
4. **净零还原**：执行完毕后在 `finally` 块中立即恢复原生 `oracledb.connect`，绝不污染后续测试。
