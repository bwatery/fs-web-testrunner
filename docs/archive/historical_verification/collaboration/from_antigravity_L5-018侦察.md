# 专题报告 · L5-018 死亡记录与死亡病例讨论（可验性侦察）

> 任务要求：先侦察库里有没有死亡患者（离院方式/死亡记录文书/死亡讨论）。有就写 flow，没有就如实报未执行 + 证据。

---

## 一、侦察结论

- **判定**：**「未执行（文书字典规范完备，但库中无死亡患者/文书样本）」**。
- **核心结论**：
  1. 电子病历文书字典 `EMR_BD_RECORD_DICT` 中完整预设了 5 类法定死亡文书规范（24小时内死亡记录、死亡病例讨论记录、死亡记录、死亡讨论记录、死亡出院记录）；
  2. 但在全库存量 519 份 `EMR_RECORD` 病历中，**死亡文书签署记录为 0 份**；住院登记 `FIN_IP_REGISTER` 中无转归为死亡的患者样本；
  3. 现场数据库属于演示/试运行环境，所有已出院患者均为好转/治愈常规出院，从未触发过真实死亡病例讨论业务。

---

## 二、调查事实与硬证据

### 1. 电子病历文书字典（标准完备）
查询 `EMR_BD_RECORD_DICT`：
```sql
SELECT RECORD_DICT_ID, RECORD_DICT_CODE, RECORD_DICT_NAME, PARENT_RECORD_DICT_ID
FROM EMR_BD_RECORD_DICT
WHERE RECORD_DICT_NAME LIKE '%死%';
```
**结果**：
- `DOC01003` (IPM-01-003): 24小时内死亡记录（归属 CAT01 入院类文书）
- `DOC03010` (IPM-03-010): 死亡病例讨论记录（归属 CAT03 会诊与转科类文书）
- `DOC05005` (IPM-05-005): 死亡记录（归属 CAT05 危重抢救类文书）
- `DOC05006` (IPM-05-006): 死亡讨论记录（归属 CAT05 危重抢救类文书）
- `DOC09003` (IPM-09-003): 死亡出院记录（归属 CAT09 出院与终末病历类文书）

### 2. 病历实例库 `EMR_RECORD`（实例为 0）
```sql
SELECT COUNT(*) FROM EMR_RECORD
WHERE RECORD_TITLE LIKE '%死%' OR TEMPLATE_NAME LIKE '%死%';
```
- **实际查询条数**：**0 条**（全库 519 份病历文书无一条包含死亡标题或死亡模板）。

### 3. 出院患者与转归排查
- 检查 `FIN_IP_REGISTER` 46 笔住院登记及历史出院患者，出院时间记录正常，但全院无一例死亡转归记录；
- 检查病程记录 `EMR_RECORD_ITEM`，无"死亡讨论主持发言"、"死亡诊断"、"死亡时间确认"等明细要素。

## 三、处理建议

因客观缺乏死亡患者数据，不硬凑假数据或编写假断言，如实判定为「未执行」。
