# HIS WebRunner - Dify & 扣子 (Coze) 智能体一键接入指南

本指南说明如何将 HIS WebRunner 的自动化测试与质检能力接入到 **Dify** 或 **字节跳动·扣子 (Coze)** 等主流大模型 Agent 平台中。

---

## 方式 1：Dify 平台导入步骤

1. 打开 Dify 控制台（本地部署或云端版）；
2. 点击左侧导航栏 **「工具 (Tools)」** ➔ 点击右上角 **「创建自定义工具」**；
3. **基本信息配置**：
   * **工具名称**：`HIS_Quality_Assurance`（HIS 智能质检外骨骼）
   * **Schema 导入方式**：选择 **OpenAPI 模式**；
4. **导入 Schema**：
   * **方式 A (推荐·URL 导入)**：直接填入 `http://127.0.0.1:8989/openapi.json`（若 Dify 跑在 Docker 或另一台机器，请将 `127.0.0.1` 替换为主机局域网 IP，如 `http://192.168.1.100:8989/openapi.json`）；
   * **方式 B (文件导入)**：直接复制项目中的 `docs/openapi_dify.json` 内容粘贴进输入框；
5. 点击 **「保存并发布」**；
6. 在您的 **聊天助手 (Chatflow)** 或 **Agent 编排应用** 中，添加刚刚创建的 `HIS_Quality_Assurance` 工具集，AI 即可在对话中自主调度测试！

---

## 方式 2：字节跳动·扣子 (Coze) 导入步骤

1. 登录 [扣子 Coze 平台](https://www.coze.cn)；
2. 进入 **「个人空间」** ➔ **「插件 (Plugins)」** ➔ 点击 **「创建插件」**；
3. **插件名称**：`HIS自动化质检`；
4. **创建方式**：选择 **基于 OpenAPI 导入**；
5. 上传或粘贴 `docs/openapi_dify.json` 文件；
6. 配置服务基础 URL 为 `http://<您的IP>:8989`，点击完成。
7. 在 Bot 编排页面中，直接勾选该插件。

---

## 智能体常用 Prompt 示例（直接复制给 Agent）

```text
你是一个医疗 HIS 医院信息系统高级自动化测试工程师与质量分析专家。
你可以通过已绑定的 HIS 工具集对全院六大工作站（住院医生站、门诊医生站、药房系统、门诊收费、住院收费、住院护士）进行自动化验收与规则校验。

当用户提出以下需求时，请自主决策并调用工具：
1. 用户说“跑一遍全院测试/六大工作站测试”：
   -> 先调用 his_run_tests(mode="ALL", headless=true)
   -> 轮询 his_get_status 查看执行进度
   -> 如果发现失败用例，调用 his_get_logs 查看详细报错原因并汇报。

2. 用户说“检查一下业务规则”：
   -> 调用 his_verify_all_rules 校验 16 条规则并输出规则健康报告。

3. 用户说“测试门诊退费/药房发药”：
   -> 调用 his_switch_identity 切换为对应角色
   -> 调用 his_run_tests 指定对应工作站
   -> 总结测试是否通过。
```
