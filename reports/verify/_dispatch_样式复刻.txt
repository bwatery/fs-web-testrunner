【样式复刻：把 UI 的 HTML 骨架对齐到原版 CSS（用户 2026-10-10 明确要求）】

> 用户原话：**「你这个 ui 设计和原来对比起来，也太丑了，你直接复刻别人的样式就行了」**
> **不是让你重做样式 —— CSS 已经是原版的，是 HTML 没跟上。**

---

# 一、诊断（主力已查实，别再猜）

```
旧 index.html 用了        136 个类名
新 index.html 只用了       13 个类名
CSS 里定义了              147 个类名
新旧 HTML 重合的类名        1 个（只有 active）
```

**`fs_runner/ui/static/css/*.css` 是从原版逐字节搬过来的**（`variables/layout/components/cases/rules` 五个文件尺寸完全一致）——
**CSS 不用动。丑的原因是新的 `index.html` 没按这套 CSS 的类名写**，
所以 `app-layout` / `content-area` / `activity-rail` / `drawer` / `card-table-wrapper` / `brand-wrap` 这些骨架类**一个都没生效**。

---

# 二、要做的：**用原版的 DOM 骨架重写新 HTML**

1. 取出原版结构作模板：
   ```
   git show 78e5337^:web_runner/static/index.html
   ```
2. **保留它的类名骨架与层级**（侧栏 / 顶栏 / 内容区 / 抽屉 / 卡片 / 表格 / 徽章 …），
   把新功能**挂到这套骨架上**，而不是另起一套 class：
   - 用例列表（五状态徽章、行内「▶ 执行」）
   - 执行控制条（执行选中 / 全部执行 / **停止** / `☑ 显示浏览器` / 慢放选择）
   - 步骤级实时提示（`current_step`）
   - 真实 / 沙盒 视觉分离
   - 点开看 evidence（库值 / 接口值 / 等式 / 遵循规则）
3. **摘掉原版里这些块**（它们在 CSS 里有对应类名，但**内容与功能必须去掉**）：
   - 「离线沙盒自适应通过（推荐·全绿灯）」
   - 「智能自愈模式」开关
   - 「🛡️ 自愈通过」徽章
   - 环境切换里的 `adaptive_strategy`
   → **类名可以留（CSS 要它），但对应的 HTML 块、JS 逻辑、接口调用一律删掉。**

> 也就是说：**样式照抄，功能换成新的，自愈那套不搬。**

---

# 三、验收（我用可量化的方式查）

1. **类名覆盖率**：新 `index.html` 里用到的类名，**≥ 90% 必须在 CSS 里有定义**
   （现在只有 1 个重合，这就是"丑"的根因）
2. **CSS 的主干类必须被用上**，至少包括：
   `app-layout` · `content-area` · `activity-rail` · `brand-wrap` · `card-table-wrapper` · `drawer`
3. **肉眼**：打开 `http://127.0.0.1:8989/`，**版式、配色、间距与旧版观感一致**（截图对比）
4. **红线不变**：`grep -rn "自愈\|全绿灯\|离线沙盒\|adaptive" fs_runner/ui/ web_runner/` **必须为空**
5. **功能不退化**：单条执行 / 显示浏览器 / 慢放 / 停止 / 五状态 / evidence 展开 **一个都不能少**
   （这是刚做好的，别为了样式改回去）
