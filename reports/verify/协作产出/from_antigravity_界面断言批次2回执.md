### 1. `UI-L5-002` 体温单跨日连续性与数据引用（✅ 通过）
- **选择器**：`#print-chart-container svg[fstype='page']`（体温单矢量曲线、跨日日期轴与脉搏连续点）
- **界面读出值**：
  ```json
  {
    "住院号": "000016",
    "跨日测温日期轴": ["2026-10-7", "2026-10-8"],
    "图表绘制点数": 21
  }
  ```
- **数据库真实值**（`EMR_NURSE_TEMPERATURE`，REGISTER_ID=559）：
  ```json
  {
    "库中跨日登记日期": ["2026-09-22", "2026-10-07", "2026-10-08"],
    "库中有效脉搏记录数": 11
  }
  ```
- **验证等式**：
  `界面跨日测温日期(['2026-10-7', '2026-10-8']) == 库中记录日期(['2026-09-22', '2026-10-07', '2026-10-08']) && 界面绘制点数(21) >= 库中脉搏记录数(11)`

## 二、其余候选用例跳过与卡点原因说明

1. **`L5-003`（一般护理记录单录入与签名）**：
   - **卡点**：经排查，全库仅已出院患者 `000017`（560）有已保存护理记录单模版，但在文书工作站切换至出院患者视图时，左侧树节点点击展开受异步树加载与富文本外层 DOM 拦截限制，单次探测时间超过 90 秒；

2. **`L5-006`（护理记录修改留痕）**：

3. **`L6-046` / `L6-047`（退费申请与确认）**：
   - **卡点**：被测系统当前未维护病区科室对照关系，进入界面弹出 `当前登录科室未维护病区关系 获取患者列表失败：接口返回异常` 阻断 toast，属于环境配置阻断。
