1. 本地 / Windows 测试机部署

            
安装 Python 依赖与 Playwright 浏览器内核，一键双击启动：

            

              
              pip install -r requirements.txt
playwright install chromium
start_webrunner.bat
            

          


          
          

            
2. 医院内网服务器集中部署

            
监听 0.0.0.0 并放行 8989 端口，供团队与外部 AI 共同调用：

            

              
              # Windows Server 防火墙放行
New-NetFirewallRule -DisplayName "HIS-TestRunner" -Direction Inbound -LocalPort 8989 -Protocol TCP -Action Allow
            

          


          
          

            
3. Windows 后台服务常驻与自启

            
使用 NSSM 注册为系统静默服务，开机自启，崩溃自愈：

            

              
              nssm install HISTestRunner "python.exe" "run_runner.py"
nssm start HISTestRunner
            

          


          
          

            
4. Docker / Linux 容器化部署

            
基于 Playwright 官方 Ubuntu 镜像构建轻量级无头容器：

            

              
              docker build -t his-runner:latest .
docker run -d -p 8989:8989 his-runner:latest
